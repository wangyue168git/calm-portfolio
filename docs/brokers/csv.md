# 导入 CSV（任何券商都能用）

没有开放接口的券商（大部分 A 股券商、雪盈等），或者你不想配令牌，都可以用这个办法：从券商导出持仓表，在电脑版导入。

## 步骤

1. 在券商 App 或网页里找到持仓列表的 **导出** 功能（常见于电脑版客户端的持仓页，右键或工具栏）。导出成 Excel 的话，用 Excel / WPS / Numbers **另存为 CSV**。
2. 打开电脑版看板，点 **组合分析** 右上角的 **导入 CSV**。
3. 选择要导入到哪个账户，再选文件。
4. 看板会自动识别 **代码、名称、数量、成本价** 四列。识别错了可以在下拉框里手动改。
5. 下面的预览会告诉你每只的变化：
   - **新增**：账户里还没有，会新建；
   - **更新**：数量或成本变了，会追加一条「CSV 导入」记录；
   - **不变**：跳过；
   - **文件里没有**：账户里有、文件里没有的持仓，**只提示、不删除**（卖光了的请手动删）。
6. 确认无误点 **确认导入**。

## 能识别的列名

不区分大小写，括号里的单位会忽略，比如「成本价(元)」也能认出来。

| 用途 | 能识别的列名（部分） |
|---|---|
| 代码 | 代码、证券代码、股票代码、Symbol、Ticker、Code |
| 名称 | 名称、证券名称、股票名称、Name、Description |
| 数量 | 数量、持仓数量、股票余额、持有数量、股数、Quantity、Position、Shares |
| 成本价 | 成本价、摊薄成本价、持仓成本价、参考成本价、买入均价、平均成本、Avg Cost、Cost Basis Price |

其他细节：

- 支持逗号、制表符、分号分隔；文件开头有几行说明文字也没关系，会自动找表头那一行。
- 国内券商常见的 **GBK 编码** 会自动识别。
- 代码前后缀会去掉：`SH600519`、`600519.SH`、`AAPL.US` 都能认。港股账户里的代码会补零到 5 位（`700` → `00700`）。
- 新建持仓的市场按账户币种猜：USD → 美股，HKD → 港股，CNY → 6/5/9 开头算沪市、其余算深市。场外基金请在页面上手动添加。
