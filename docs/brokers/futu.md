# 富途 / moomoo

**目前没有内置。** 原因不在代码，在部署：

富途 OpenAPI 不能直接拿令牌访问，必须先在服务器上运行富途的 **OpenD 网关程序**，用富途账号登录并保持在线（中间可能需要手机验证），看板再连 OpenD 查询持仓。对大多数人来说，这比看板本身还难维护。

## 现在可以怎么用

**办法一：导出 CSV（推荐）**

在富途牛牛 / moomoo 电脑版的持仓列表里导出持仓（具体位置以当前版本为准），另存为 CSV，在电脑版看板用「导入 CSV」。见 [csv.md](csv.md)。

**办法二：自己接 OpenD（适合会写一点代码的用户）**

1. 按富途官方文档在服务器上部署并登录 OpenD（社区有 Docker 镜像可参考）。
2. 写一个小适配器，用富途官方的 Node SDK（npm 包 `futu-api`）连 OpenD，查询持仓列表，返回看板要的格式。接口约定见 [custom.md](custom.md)。
3. 只用查询接口即可，**不需要也不要解锁交易**。

如果你做成了、愿意分享，欢迎提 PR，我们可以把它变成内置选项。
